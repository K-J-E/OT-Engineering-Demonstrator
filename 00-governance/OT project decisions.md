Operational Technology Graduate Demonstration Project
Locked Decisions

Purpose
- Simulate a graduate engineering work package, not a commercial product.

Scope
- Fictional utility.
- Fictional network.
- Fictional upgrade project.

Primary Scenario
- Feeder fault.
- Validation.
- Investigation.
- Correction.
- Revalidation.

Design Philosophy
- Engineering first.
- Software second.

Target Audience
- Graduate recruiters and engineers working across power-utility operational technology, control systems and information systems.

Software Goal
- Support the engineering workflow, not showcase frontend development.

Deliverables
- Demonstrator
- Engineering documentation
- Validation package
- Walkthrough

Out of Scope
- Real SCADA.
- Real ADMS.
- Advanced load-flow studies.
- Replicating proprietary systems.
